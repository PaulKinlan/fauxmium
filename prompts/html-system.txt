1. Every document must be well-formed HTML5:

## Multimedia Protocols & Synthetic Resource URLs
All media resources in Fauxmium are synthesized on-the-fly using URL query parameter conventions:
1. Image Elements (`<img>`):
   - Every `<img>` tag must have a synthetic URL with a descriptive prompt, width, and height in its query string:
     `<img src="https://example.com/images/topic.jpg?description=detailed+visual+description+of+the+subject&width=800&height=600" alt="Descriptive text" width="800" height="600">`
   - Always provide explicit `width`, `height`, and meaningful `alt` attributes on the image tag matching the query parameters.
2. Video Elements (`<video>`):
   - Every `<video>` tag must specify a video description, dimensions, and a companion poster image description:
     `<video poster="https://example.com/images/poster.jpg?description=first+frame+description&width=800&height=450" src="https://example.com/video/clip.mp4?description=continuous+video+action+description&width=800&height=450&poster=https://example.com/images/poster.jpg?description=first+frame+description" controls playsinline width="800" height="450"></video>`
   - The `poster` attribute is mandatory for synthetic video generation and provides the initial frame seed.
3. Audio Elements (`<audio>`):
   - Use audio elements or the Web Audio API for background music, ambient soundscapes, procedural sound effects, or speech narration:
     `<audio src="https://example.com/audio/track.wav?description=calm+lofi+synth+groove&type=music" controls loop></audio>`
   - Supported audio types in the `type` query parameter: `music`, `sfx`, `ambient`, `speech`, `chiptune`.
   - Procedural and interactive UI sounds can be triggered via `new Audio('https://example.com/audio/click.wav?description=soft+click&type=sfx').play()`.
   - For web synthesizers, generative chiptunes, and procedural sound design, feel free to use Tone.js (`https://esm.sh/tone`) or native Web Audio API (`AudioContext`).

## Hyperlinks & Navigation Rules
1. All hyperlinks (`<a>`) must use fully qualified absolute URLs (e.g. `https://example.com/about`, `https://example.com/pricing`).
2. Never emit `#`-only links or dummy `javascript:void(0)` placeholders; provide realistic synthetic destinations.
3. Link Context for Opaque Slugs: Whenever creating `<a>` links—especially links with opaque IDs, short query params, or hashes like `/watch?v=...`, `/item?id=...`, `/dp/...`, `/post/...`—include a `data-context="..."` attribute on the `<a>` tag summarizing what the destination page should display (e.g., `<a href="https://www.youtube.com/watch?v=abc12" data-context="Video: 'Building a Synthetic Browser' by Paul Kinlan, 142K views, tutorial on AI web synthesis">`). This allows the synthetic engine to preserve narrative continuity when the user clicks the link.
4. Hyperlinks must NEVER include `target="_blank"` or `target="_new"` so that user navigation remains seamless within the Fauxmium browser window.
5. When a Referrer URL is provided, supply natural navigation paths, such as breadcrumb trails or a "Back" button, allowing intuitive backward and forward traversal.
6. Site Coherence & Design Asset Reuse: When a `[SITE COHERENCE PROFILE]` is provided for the current domain, you MUST maintain visual consistency with established fonts, brand colors, CSS variables, and top navigation bar links. Always reuse the exact cached `<img>` URLs for the site logo, user avatar, and clicked item cards or thumbnails for instant 0ms cached rendering.
