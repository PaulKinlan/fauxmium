        Core Capabilities
        
Engineering an Infinite Web

        

          Fauxmium pairs prompt prefix caching, procedural audio generation, and site memory to make AI web exploration fast, cohesive, and economical.
        

      


      

        

          
🌐

          
Multi-Modal Synthesis

          

            Synthesizes HTML, vector SVG, procedural WAV audio, and video streams in a unified pipeline. The server dynamically routes requests to appropriate AI models or fast local synthesizers.
          

        


        

          
🕶️

          
Browsing Lenses

          

            Transform any website into alternate temporal or aesthetic worldviews (Retro 90s, Cyberpunk 2077, Neo-Brutalist, Film Noir, Arcade 8-Bit) across typography, layout, color palette, and audio.
          

        


        

          
🧬

          
Site Memory & Design DNA

          

            Solves LLM amnesia by capturing navbar structure, brand tokens, and CSS variables across pages. When clicking a link, the originating card snippet is injected to guarantee logical continuity.
          

        


        

          
⚡

          
Prompt Prefix Caching

          

            Structures invariant system prompts (>1,024 tokens) and tiers viewport dimensions to 64px buckets. Delivers up to 75% LLM cost reduction and sub-second generation latencies.
          

        


        

          
📼

          
Byte-Range Media Streaming

          

            Implements standard HTTP 206 Partial Content range requests for video playback. Supports timeline seeking, chunk streaming, and companion poster frame visual seeding.
          

        


        

          
📊

          
Companion Extension Accounting

          

            Redesigned Chrome Extension displays live session token counts, prompt caching discounts, multi-modal asset breakdowns, and hot-swaps Browsing Lenses without restarting the server.
          

        

      

    

  


  
  

    

      

        System Design
        
Multi-Modal Request & Cache Pipeline

        

          Fauxmium sits between Chrome and the internet, intercepting every HTTP/HTTPS request and translating it into structured, cached prompts.
        

      


      

        
Request Interception & Synthesis Flow

        
[Browser / Chrome]
        │
        ▼ (HTTP / HTTPS Request)
[Fauxmium Proxy Server (127.0.0.1:3991)]
        │
        ├── Accept: text/html
        │     ├── Invariant System Prompt (>1,024 tokens) ───► [PROMPT CACHE HIT: 75% OFF]
        │     ├── Decomposed Route + Site Memory (CSS/Brand)
        │     ├── Link Intent Context (Clicked Card + Target URL)
        │     └── AI LLM (Gemini 3.8 / GPT-6 / Claude 5.5) ──► Complete HTML Page
        │
        ├── Accept: image/* or /image/
        │     ├── Dimensions, Role (hero, icon, thumbnail), Brand Colors
        │     └── Imagen 4 / DALL-E 3 / SVG Placeholder ─────► Vector/Raster Image
        │
        ├── Accept: video/* or /video/
        │     ├── Camera Motion, Aspect Ratio, Seed Poster Frame
        │     ├── Veo 3.1 Fast / Local Fallback MP4
        │     └── HTTP 206 Byte-Range Response ──────────────► Seeking Video Stream
        │
        └── Accept: audio/* or /audio/
              ├── Audio Type (chiptune, synth, speech, ambient), BPM, Mood
              └── Zero-Dependency Node.js PCM WAV Synth ─────► 16-Bit Audio Buffer
        

      


      

        

          
Prompt Prefix Caching Architecture

          

            Both Anthropic and Gemini cache prompt prefixes when the invariant prefix exceeds 1,024 tokens. Fauxmium groups the system prompt into a static block followed by 64px viewport tiers (e.g. 1920×1080), avoiding cache busting when browser windows resize slightly.
          

        

        

          
Zero-Dependency Audio Synthesis

          

            When --audio-provider synth is active, Fauxmium generates 16-bit uncompressed PCM WAV files directly in Node.js using Math.sin, ADSR envelopes, low-pass filters, and formant speech synthesis. No external binaries or paid APIs needed.

        Synthesizer API
        
Multi-Modal URL Parameter Specification

        

          Fauxmium's prompt engine instructs models to author declarative media URLs with query parameters that guide image framing, video cinematography, and audio characteristics.
        

      


      

        

          
            

              Tag / MediaType
              Supported Query Parameters
              Description & Behavior
              Example Usage
            

          
          
            

              <img>
              description, width, height, role, aspect_ratio
              
                Guides image composition. role (hero, logo, icon, avatar, thumbnail) influences shot framing and detail density. Inherits site CSS brand palette.
              
              /img/hero.jpg?description=retro+cyberdeck&width=1280&height=720&role=hero
            

            

              <video>
              description, width, height, camera, poster_description, aspect_ratio
              
                Configures Veo 3.1 video generation. camera specifies motion (dolly, pan, static, orbit). poster_description seeds the companion poster frame for visual continuity.
              
              /video/demo.mp4?description=quantum+engine+spin&camera=orbit+slow&poster_description=core+offline
            

            

              <audio>
              description, type, bpm, mood, transcript, voice
              
                Generates procedural WAV audio or TTS. type (chiptune, synth, speech, ambient, sound-effect) dictates synth oscillator shapes. transcript scales speech duration.
              
              /audio/bg.wav?type=chiptune&bpm=140&mood=energetic&description=boss+fight+stage
